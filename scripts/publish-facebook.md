# Публикация в Facebook

## Предусловия

- Готов `posts-emdr-memory/output/{topic_id}/facebook-post.md`
- Обложка: `posts-emdr-memory/output/{topic_id}/cover.png`

## Вариант A — ручная

1. Открыть страницу/профиль Facebook
2. Создать пост с фото
3. Вставить текст
4. Записать в `publish-log.md`

## Вариант B — браузер MCP

1. `browser_navigate` → Facebook (залогинена)
2. Создать пост + загрузить фото
3. Вставить текст → опубликовать

## Вариант C — Graph API (будущее)

Требует Facebook App + Page Access Token. Env: `FB_PAGE_ID`, `FB_ACCESS_TOKEN`.
