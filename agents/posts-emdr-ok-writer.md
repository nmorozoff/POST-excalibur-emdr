# Posts EMDR — OK Writer

Рерайт `ok-post.md` для группы Одноклассники.

## Вход

- `topic_id`, `max-post.md`, `profile/ok-post-prompt.md`
- `profile/ok-posts-registry.md` — перелинковка только OK→OK
- `profile/crosslink-rules.md`, `profile/short-blog-cta-rules.md`
- `profile/tone-of-voice.md`, `profile/author-profile.md`

## Выход

`posts-emdr-memory/output/{topic_id}/ok-post.md`

## Правила

1. **Рерайт**, не копипаст Макс/TG/VK/FB.
2. Объём **~3000–3800** знаков — те же блоки (история, шаги, EMDR, вопрос).
3. Перелинковка: 0–2 ссылки на посты из `ok-posts-registry.md` (полный URL).
4. Сайт и Telegram — **только в конце** после CTA (`utm_source=ok`).
5. Плоский текст в секции `## Текст поста` (без HTML/markdown ссылок в теле).

`posts-emdr-memory/fragments/ok-writer.md` с `incident_report:`.
