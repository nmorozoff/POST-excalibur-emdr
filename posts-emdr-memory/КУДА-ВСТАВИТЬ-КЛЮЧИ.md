# Куда вставить ключи

Все файлы **уже созданы** — вам нужно только открыть и вставить значения после `=`.

| Сервис | Файл | Что вставить |
|--------|------|--------------|
| **Макс** (бот для черновиков) | [`max.env.local`](./max.env.local) | `MAX_BOT_TOKEN`, `MAX_CHAT_ID` |
| **Runware** (обложки GPT Image 2) | [`runware.env.local`](./runware.env.local) | `RUNWARE_API_KEY` |
| **Telegram** (опционально) | [`telegram.env.local`](./telegram.env.local) | или через [mcp-kv.ru](https://mcp-kv.ru) |

## Быстро открыть в Cursor

**Cmd+P** и введите имя файла: `max.env.local`

## Из терминала (macOS)

```bash
cd "/Users/natala/Documents/Проекты СURSOR/Посты EMDR"
open -a Cursor posts-emdr-memory/max.env.local
open -a Cursor posts-emdr-memory/runware.env.local
```

Или одной командой:

```bash
./scripts/open-secrets.sh
```

## ⚠️ Не присылайте токены в чат Cursor

Только в локальные `.env.local` файлы — они в `.gitignore`.
