# Промпт — пост b17.ru (блог, короткая заметка)

**Файл:** `output/{topic_id}/b17-blog-post.md`  
**UTM:** `utm_source=b17`  
**Объём:** **1000–1600 знаков** (ближе к полному смыслу `max-post.md`, не урезать до 400–800)

## Тон

Чуть более профессиональный, чем Telegram — это профильная площадка психологов.  
Допустимо: EMDR, интегративный подход, «в практике вижу».

## Структура файла

```markdown
## Заголовок

{заголовок одной строкой}

## Текст поста

{текст}

## Мета
```

## Правило рерайта

- Брать **смысл и примеры** из `max-post.md`, не сжимать агрессивно.
- Можно добавить 1–2 профессиональных абзаца («в практике вижу», «как отличить»).
- **Не** превращать наблюдение в сухой список без связки.

## CTA

Читать `profile/short-blog-cta-rules.md`:

- **Каждый пост:** открытый вопрос + мягкий контакт (ЛС или сайт).
- **Каждый 4-й MSP (#04, #08…):** полный CTA пробной сессии одной строкой в конце.

## Правила b17

- **Без ссылок** в тексте заметки (ни http, ни markdown-ссылок).
- Мягкий контакт — только «напишите в ЛС на b17».
- При публикации скрипт сам: латиница из названия, раздел **Мысли о психологии**, чекбокс **Я — автор текста заметки**.

## Обложка — обязательно (в теле заметки)

| Поле | Правило |
|------|---------|
| Файл | `output/{topic_id}/cover.png` — **тот же**, что сгенерирован на шаге Макс |
| Где видят читатели | **внутри текста заметки** (первая картинка в TinyMCE), **не** только «Картинка для анонса» в настройках |
| Скрипт | `publish-b17-blog.py` вставляет `cover.png` в начало текста автоматически |

**Не использовать** поле «Картинка для анонса» как единственное место обложки — в ленте/тексте её не видно.

В блоке **Мета** файла `b17-blog-post.md`: `Обложка: cover.png — в тексте заметки (скрипт)`.

Пример мягкого контакта:

```
Если тема откликается — напишите в личные сообщения здесь на b17.
```

## Публикация

```bash
python scripts/publish-b17-blog.py --topic {topic_id}
```

Скрипт: заголовок, текст **с обложкой внутри**, мета формы, снятие «черновик». Остаётся нажать «Сохранить изменения».
