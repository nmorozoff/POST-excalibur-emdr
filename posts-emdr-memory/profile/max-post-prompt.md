## Заголовок и терминология

| Правило | Пример |
|---------|--------|
| В заголовке и обложке — **профессиональный термин** | «Паническая атака ночью», не «Паника в 3 ночи» |
| «Паника» в теле — только как разговорное узнавание («ночная паника»), не в title |
| Заголовок поста = заголовок на обложке (одна формулировка) | Синхронизация обязательна |

**Структура заголовка (эксперт):**
1. Заголовок (8–12 слов) — интрига + польза
2. Подзаголовок (15–25 слов) — усиление, контекст

---

## Архитектура текста

1. **Крючок** — сенсорная сцена (время, тело, мысль)
2. **Узнавание** — «знакомо?», без снисхождения
3. **Механизм** — простым языком (миндалина, заряд, фасад днём)
4. **Микроистория** — из практики (композитная, правдоподобная)
5. **Практика** — шаги с пояснением *почему* работает
6. **Поворот** — «дыхание не снимает заряд»
7. **EMDR-блок** — развёрнуто, см. `emdr-evidence.md`
8. **Ссылки** — сайт по теме + EMDR «ТУТ», с `?utm_source=max` (см. `profile/utm-sources.md`)
9. **CTA** — ЛС в Макс со ссылкой
10. **Вопрос** — вовлечение в конце

### Ритм (очеловечивание)

- **70%** — структура, польза, экспертность
- **30%** — живость: сенсорные детали, паузы, 1 короткая фраза на абзац максимум
- **Запрет:** цепочки из 3–5 односложных предложений подряд («автоматная очередь»)
- Предложения 2–4 строки чередовать со средними; длинные — для погружения

## Блок EMDR (обязателен, если тема про тревогу/панику/травму/фобию)

Не писать: «Метод признан ВОЗ».

Писать развёрнуто:
- ВОЗ, **2013**, EMDR в рекомендациях при **ПТСР** (взрослые, дети, подростки)
- VA/DoD США, NICE — как подкрепление статуса
- Контекст: военные, полиция, экстренные службы — где нужна быстрая переработка травмы
- Связь с темой поста (застрявший заряд → ночные пробуждения)

Скрытая ссылка:
```markdown
Ещё подробнее о методе EMDR можно почитать на моем сайте [ТУТ](https://morozovanatalia.ru/emdr-therapy?utm_source=max).

Подробнее о [теме] на моем сайте [ТУТ]({site_url по теме}?utm_source=max).
```

## CTA Макс (обязательный формат)

Перед вопросом в конце — **обязательно** (два «ТУТ»: сайт с UTM + ЛС без UTM):

```markdown
Записаться на бесплатную пробную сессию можно на моем сайте [ТУТ]({site_url по теме}?utm_source=max) или написать мне в ЛС [ТУТ](https://max.ru/se13417616_biz/AZ9H9rFePFc).

А у вас бывало: …? 👇
```

**Не использовать** старый блок «Если узнали себя — напишите в ЛС» / «Разберём… пробную сессию» — его заменяет фраза выше.

**Короткие посты (очередь `sb-*`):** мягкий контакт по `profile/short-blog-cta-rules.md` (без «Если откликается…»). Полный CTA сессии — каждый 4-й MSP (#04, #08…).

Контакт Макс: `https://max.ru/se13417616_biz/AZ9H9rFePFc`

## Шаблон #17 — личная история (обтекаемый)

**Когда:** `17-personal-story`, посты серии WB #4, любая «я тоже проходила через…»

**Голос:** как рассказ вслух — плавно, с паузами, в удовольствие читать. Не конспект и не «пост от нейросети».

| Делать | Не делать |
|--------|-----------|
| Одна дуга: захват → тело/страх → выдох → урок → мостик к читателю | Подзаголовки-рубрики внутри текста |
| Конкретные сцены: горло сжалось, стирала сообщение, не брала трубку | Триады «Вы не слабый / не плохой / не…» |
| Короткие фразы **внутри** длинного абзаца, не списком | Маркированные списки там, где можно prose |
| «Я помню…», «Сейчас, когда смотрю…» — живая Наталья | Одинаковые конструкции в каждом абзаце |
| Обтекаемо: без дат, сумм, ниши, названий (если brief так требует) | Шаблонные мостики «Важно понять одну вещь» |

**Объём:** для личной истории допустимо **2800–3400** знаков, если текст цельный. Не раздувать ради 3500.

**CTA:** по brief — мостик к SOS мягко, без жёсткого оффера (если не `cta:sos`).
