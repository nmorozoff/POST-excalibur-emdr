# Промпт — пост TenChat

**Файл:** `output/{topic_id}/tenchat-post.md`  
**UTM:** `utm_source=tenchat` (только в ссылке в тексте, не на обложке)  
**Объём:** **1800–2200 знаков** (полный смысл `max-post.md` + раскрытие)

## Тон

Экспертность + личный опыт; короткие абзацы, списки, подзаголовки жирным.  
Без продажи в каждом абзаце.

## Правило рерайта

- **Не кастрировать** текст: сохранить наблюдение → инсайт → различие → вопрос.
- Целевой объём **1800–2200** знаков; раскрыть «как отличить», «что внутри», примеры из жизни.
- Списки — только с маркером `—` в начале строки (скрипт конвертирует в `<ul>`).
- Короткие строки-наблюдения **без** маркера — отдельные абзацы, не список.

## Структура файла

```markdown
## Заголовок (≤ 80 символов)

{заголовок}

## Текст для вставки в приложение (копировать целиком)

{текст с **жирным** и [ссылкой в слове](url)}

## Мета
```

## Обложка — обязательно

| Поле | Правило |
|------|---------|
| Файл | `output/{topic_id}/cover.png` — **тот же**, что сгенерирован на шаге Макс |
| Как прикрепить | кнопка **скрепка** в редакторе (не внутри markdown-текста) |
| Скрипт | `publish-tenchat-post.py` — скрепка + `cover.png` автоматически |

В блоке **Мета** файла `tenchat-post.md`: `Обложка: cover.png — скрепка (скрипт)`.

## Форматирование (веб `tenchat.ru/editor`)

- Абзацы через пустую строку
- **Жирный** — `**текст**` (скрипт конвертирует в HTML)
- Ссылка в слово: `[тревожности](https://morozovanatalia.ru/...?utm_source=tenchat)` — **не** голый URL
- Тематика: **Саморазвитие** (по умолчанию)

`profile/short-blog-cta-rules.md` — открытый вопрос + ссылка на сайт в слове (TenChat).

## Публикация

```bash
python scripts/publish-tenchat-post.py --topic {topic_id}
```

Скрипт: заголовок, текст, тематика, **обложка через скрепку**. Остаётся нажать «Опубликовать».
