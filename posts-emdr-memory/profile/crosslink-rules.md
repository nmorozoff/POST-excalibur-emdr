# Перелинковка между постами (все соцсети)

## Реестры (отдельно по платформе)

| Платформа | Файл |
|-----------|------|
| Макс | `profile/max-posts-registry.md` |
| Telegram | `profile/telegram-posts-registry.md` |
| VK профиль | `profile/vk-profile-posts-registry.md` |
| VK группа | `profile/vk-group-posts-registry.md` |
| Facebook | `profile/facebook-posts-registry.md` |

**Не смешивать URL между платформами.** В посте Telegram — ссылка на пост Telegram, в VK профиле — на пост VK профиля, в VK группе — на пост группы.

LinkedIn отменён.

---

## Когда писать новый пост

1. Прочитать реестр **той платформы**, для которой пишете рерайт.
2. Найти 0–2 темы с пересекающимися **тегами**.
3. Вставить **1 нативную фразу** со ссылкой на пост **в этой же сети** (не копипаст из Макс).
4. Смысл и факты не менять — только формулировка (рерайт).

Примеры:
- Макс: `О ночных панических атаках мы уже говорили [здесь](max_url).`
- Telegram: `О ночных атаках писала <a href="tg_url">здесь</a>.`
- VK профиль: `О ночных атаках мы уже говорили [https://vk.com/wall218367867_641|здесь].`
- VK группа: `О ночных атаках писали [https://vk.com/wall-224685309_144|здесь].`
- Facebook: `…здесь: fb_url` (внешний анкор тоже недоступен — полный URL)

---

## Рерайт (обязательно)

| Из → В | Правило |
|--------|---------|
| Макс → Telegram | +10–15% глубины, HTML, **рерайт** |
| Макс → VK профиль | больше «я», **рерайт**, тот же объём ~3000 |
| Макс → VK группа | экспертнее, списки, **рерайт**, тот же объём |
| Макс → Facebook | теплее, эмодзи умеренно, **рерайт** |

**Запрет:** копипаст текста Макс в TG/VK/FB.

---

## После публикации

Добавить строку в реестр **этой платформы**:
- `topic_id`, дата, заголовок, URL поста, `site_url`, теги
- VK группа: отдельная строка в `vk-group-posts-registry.md`
- VK профиль: отдельная строка в `vk-profile-posts-registry.md`
- Telegram: строка на каждый канал (или основной + пометка в индексе)

Скрипт (опционально, **один реестр за вызов**):

```bash
python scripts/update-post-registry.py --platform telegram --topic-id 02-airplane-panic \
  --title "..." --url "https://t.me/morozova_emdr/..." --site-url "https://morozovanatalia.ru/phobias" \
  --channel @morozova_emdr --message-id 599 --tags "паника,авиафобия"
```

Платформы: `max` | `telegram` | `vk-profile` | `vk-group` | `facebook`
