## EMDR — ключевой метод (добавлено 2026)

### Что это для контента

EMDR (Eye Movement Desensitization and Reprocessing) — **научно признанный ВОЗ метод** переработки травматического опыта. Не разговорная терапия «годами о детстве». Работа с **застрявшим зарядом** в нейронных сетях через билатеральную стимуляцию (движения глаз, тактильные стимулы).

### Для кого пишем

- Панические атаки, фобии, тревога, ПТСР, горе
- «Понял инсайт — ничего не изменилось»
- Психосоматика при «всё в норме» у врачей
- Предприниматели: выгорание, страхи, стеклянный потолок, токсичные паттерны
- Отношения, границы, созависимость, доверие после измены

### Как говорить о EMDR

| Да | Нет |
|----|-----|
| «Застрявшая программа в мозге» | «Эзотерика / магия» |
| «1–3 сессии на конкретный заряд» | «Вылечим всё за раз» |
| «Тело перестаёт реагировать на триггер» | «Простим всех обидчиков» |
| «ВОЗ, нейрофизиология» | «Энергии / чакры» |
| «Не сочувственное кивание годами» | «Давайте поговорим о маме» |

### Результаты, которые называем

- Спокойный перелёт, сон, отсутствие паники
- Увольнение токсичного без вины
- «Кристальная тишина» вместо фоновой тревоги
- Реакция на триггер стирается, не «учимся справляться»
