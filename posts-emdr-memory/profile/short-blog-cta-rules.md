# CTA — короткие посты (очередь MSP) vs длинные (WB / site)

## Конфликт, который был

| Источник | Правило |
|----------|---------|
| **MSP Этап-2** (b17/TG/MAX) | CTA на консультацию — **редко** (1–2 из 10), в основном открытый вопрос |
| **Posts EMDR orchestrator** | Полный CTA «бесплатная пробная сессия + ЛС» — **в каждом** посте |

Пост `sb-01` вышел **без** призыва в ЛС/на сессию, потому что при генерации следовали MSP-брифу, а не orchestrator. **Переделывать опубликованное не нужно** — правило фиксируем на будущее.

## Гибрид (с #2 в очереди MSP)

### В каждом коротком посте — три слоя финала

1. **Открытый вопрос** (обязательно) — личный, конкретный.
2. **Мягкий контакт** (обязательно) — одна строка, без «продажи». **Не использовать:** «Если откликается — напишите в личные сообщения» (топорно).

   Выбрать **одну** формулировку (чередовать по номеру поста `sb-NN % 3`):

   | Слот | Макс / VK / FB (markdown) | Telegram (HTML) |
   |------|---------------------------|-----------------|
   | 0 | Если хотите обсудить это лично — я на связи в [личных сообщениях]({ls_url}). | Если хотите обсудить это лично — я на связи в <a href="{ls_url}">личных сообщениях</a>. |
   | 1 | Когда хочется разобрать свой случай — напишите мне [в ЛС]({ls_url}). | Когда хочется разобрать свой случай — напишите мне <a href="{ls_url}">в ЛС</a>. |
   | 2 | Если тема про вас — можно написать [в личку]({ls_url}), разберём аккуратно. | Если тема про вас — можно написать <a href="{ls_url}">в личку</a>, разберём аккуратно. |

   **ЛС:** Макс → `https://max.ru/se13417616_biz/AZ9H9rFePFc`; TG/VK/FB → `https://t.me/natalyamorozovaa`.

3. **Ссылка на сайт** (только после CTA, не в теле поста):
   - «Подробности о проведении сессии, стоимости и записи читайте [ТУТ]({site_url}?utm_source=…).»
   - Никаких ссылок на сайт в середине поста — только перелинковка внутри платформы.

4. **Полный CTA сессии** (не в каждом посте):
   - каждый **4-й** пост MSP (`#04`, `#08`, …), **или**
   - явный флаг в очереди: `cta:session`.

Полный CTA (как в длинных постах):

```
Если хотите обсудить это лично, напишите мне в ЛС ТУТ.

Подробности о проведении сессии, стоимости и записи читайте ТУТ.
```

### Длинные посты и серия WB

Без изменений: **полный CTA в каждом** (`posts-emdr-orchestrator.mdc`, `00-brief.md`).
