# Приписка про клиентские истории (обязательна)

**В каждом посте** — в самом конце, **после** CTA, ссылки на сайт и открытого вопроса.

## Текст (канон)

> Все истории публикуются только с разрешения клиентов, все имена вымышленные, все совпадения случайны.

Не сокращать. Не перефразировать. Одна строка.

## По платформам

| Платформа | Формат |
|-----------|--------|
| Макс | Курсив markdown: `_*текст*_` |
| Telegram | HTML: `<i>текст</i>` — внутри `## Текст поста`, перед `<!-- END_POST -->` |
| VK профиль / группа | Плоский текст, без markdown |
| Facebook | Плоский текст |
| Одноклассники | Markdown в исходнике: `[ТУТ](url)`, `**жирный**`; при MCP publish → plain (см. `format_ok_publish_text`) |
| b17 | Плоский текст в `## Текст поста` |

## Порядок финала поста

1. Открытый вопрос (если есть)
2. Мягкий контакт / CTA + ЛС
3. Ссылка на сайт (`ТУТ` + UTM)
4. **Приписка** ← всегда последняя строка контента

## Когда истории нет

Если в посте нет кейса/имени клиента — приписку **всё равно** ставить (универсальное правило канала).
